How the value is priced

For each category, the multiple is the median mcap / TVL of the live-token protocols in that category (119 live peers in this snapshot). Categories with fewer than 3 live peers use the global median (). Multiples are clamped to [0.05, 1.50].

implied = max(1, round( TVL × multiple × (1 + clamp(7d, −50, 100)/100 × 0.35) × (0.7 + min(age, 1460)/1460 × 0.5) × (1 + 0.03 × min(chains, 5)) ))

Growth, age and chain breadth are the only adjustments. No name is ever special-cased; the same function scores every row. A protocol “records no token” means DefiLlama carries no market cap, CoinGecko id or symbol for it — not proof it has none.
